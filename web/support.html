遇到问题

最快的办法是在 GitHub 上提 issue：github.com/pervio/Pervio/issues。连不上这类问题，请写上电脑的系统版本、Claude Code 有没有登录（在电脑的终端里跑一次 claude 就知道）、Mac 的「远程登录」有没有打开（系统设置 → 通用 → 共享 → 远程登录）。

常见问题

  • 连不上？手机和电脑要在同一个网络里（或者经过你自己的 VPN、Tailscale），Mac 上要打开「远程登录」。
  • 没有回复？先确认电脑上引擎的命令（claude、codex 或 agent）能用、已经登录。Pervio 只是遥控器，引擎在你的电脑上。
  • 收不到通知？app 开着的时候通知马上就到。锁屏推送不用配置，但要在 iOS 设置里允许 Pervio 的通知，而且手机要连上过这台电脑一次（手机是在连接时把推送凭证交给电脑的）。

说明

Pervio 是免费、开源的个人项目，不保证多久回复，但每个 issue 都会看。
