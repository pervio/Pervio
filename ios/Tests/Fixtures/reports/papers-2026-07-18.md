### 看着答案写的思维链,会毒化推理蒸馏数据(原题:Answer-Conditioned Chains of Thought Degrade Verifiable-Reasoning Distillation in Large Language Models)
[4.5/5 · 命中:研究方向第2条] arXiv:2607.14552 · Jungseob Lee et al. · https://arxiv.org/abs/2607.14552
- 做了什么:固定生成器、题目集与正确性过滤,只改一件事——是否把金标答案展示给生成器再让它写一条「通向该答案」的链。结果:在这种链上微调会显著拉低可验证推理成绩,最难竞赛题上最多掉约 27 分;危害在八个思维模型、四个家族间可复现、跨教师家族可迁移。
- 差分:大家早知道错误答案会污染蒸馏数据,所以用正确性过滤兜底;本文新的一步是证明「答案正确但由答案倒推出来的链」同样有毒,而过滤对此失明,并用 prompt 消融把毒源定位到「向答案合理化」的指令本身,而非答案可见性。
- 对你的启示:蒸馏管线里的 gold-conditioned 补采样应换成 answer-blind 重采样加大预算;摘要指出「过早报出最终答案」是可测症状,这意味着可以把它做成一个廉价探测器,对已囤积的 SFT 推理数据回溯排毒(推断)。

### 静态相关性预测不了 agent 搜索里的因果效用(原题:Bridge Evidence: Static Retrieval Utility Does Not Predict Causal Utility in Multi-Step Agentic Search)
[4.5/5 · 命中:研究方向第1条] arXiv:2607.15253 · Debayan Mukhopadhyay et al. · https://arxiv.org/abs/2607.15253
- 做了什么:在 HotpotQA 上重放 1000 个 ReAct 轨迹,对 agent 读过的每篇文档做「删掉再续跑」的反事实,共 23,322 个观测:因果效用与静态 RAG 效用接近统计独立(Spearman −0.026),约三分之一文档静态看无用、因果上却承重。
- 差分:agentic RAG 的检索器至今仍按单轮「读了答案变好没」来训练与评估;本文第一次用反事实轨迹重放直接量化两者的分离,并给出机制——bridge 文档的价值在于交给 agent 一个判别性实体去改写下一跳查询(此类实体进入下一查询的频率高 4.02 倍)。
- 对你的启示:为 agent 训练 retriever/reranker,监督信号应从静态 qrel 换成轨迹级反事实或其代理;它的 CTU 三元组(答案质量/下一跳检索质量/轮数)现成就是 agent 搜索的一个 process reward 定义,可直接接进 RL(推断)。
- 保留意见:只在 HotpotQA + ReAct 一个组合上验证,对原生 agentic 训练过的强模型是否同样分离,摘要未说明,需看正文确认。

### 把自己的轨迹提炼成技能,再蒸馏回策略(原题:SEED: Self-Evolving On-Policy Distillation for Agentic Reinforcement Learning)
[4.5/5 · 命中:研究方向第1、2条] arXiv:2607.14777 · Jinyang Wu et al. · https://arxiv.org/abs/2607.14777
- 做了什么:针对 agentic RL 轨迹级稀疏奖励与 token 级学习之间的监督鸿沟,让策略自己从完成的轨迹里总结自然语言「事后技能」,再用技能增强前后的动作概率偏移构造稠密 token 级蒸馏信号,与 outcome RL 联合优化;文本与视觉 agent 任务上性能与样本效率提升,代码开源。
- 差分:与测试时检索的 memory/skill 库不同,这里技能在训练时随策略共同演化并蒸馏回权重;与常规 on-policy distillation 不同,教师就是「带 hindsight 技能的自己」,不依赖外部强模型。
- 对你的启示:「技能条件下的概率偏移」本质是把 episode 结果折算到 token 的 credit assignment 装置;它的重打分模块与 RL 主干解耦,可以先单独接到你现有的 GRPO 流程上验证稠密信号的增益,不动训练栈其余部分(推断)。
- 保留意见:摘要只说「一致提升」,未给出基准名称与具体幅度,需看正文确认。
